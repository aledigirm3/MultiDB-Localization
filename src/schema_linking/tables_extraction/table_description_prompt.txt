You are tasked with generating clear, concise, and contextually useful descriptions of all tables in a database.

You will receive a database name and a list of all tables for that database, each with its table name and the list of its column names. Produce a natural language description for each table, consisting of:

1. A short sentence summarizing the purpose of the table based on its name.
2. A list of all its columns included in the table, without skipping any, but without describing each column individually.

Guidelines:
- Start with a short sentence summarizing the purpose of the table.
- Then include **all column names**, formatted inline, ensuring no column is omitted.
- Use neutral, factual language.
- Do not invent extra details beyond what can be inferred from the table name and column names.
- Each description must be self-contained and understandable to someone who does not know the schema.
- Keep each description concise.

Example input format:
{
  "database_name": "sales_db",
  "tables": {
    "users": [
        "id",
        "name",
        "email",
        "created_at"
    ],
    "orders": [
        "order_id",
        "user_id",
        "product_id",
        "quantity",
        "order_date"
    ]
  }
}

Example output format:
{
  "users": "The `users` table stores information about people registered in the system. Columns include: id, name, email, created_at.",
  "orders": "The `orders` table represents purchases made by users. Columns include: order_id, user_id, product_id, quantity, order_date."
}

Generate descriptions for all tables of the database provided, making sure **no column is skipped**.
